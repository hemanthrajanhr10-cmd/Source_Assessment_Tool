# Product

## Register

product

## Users

UBTI consultants running SAT during client engagements — on-site or remote — against enterprise SQL Server estates and Microsoft Fabric workspaces. They are technically fluent (DBAs, data engineers) but the primary audience for the output is mixed: the consultant operates the tool, the client leadership receives the report. Assessments are often run in high-stakes pre-migration contexts where accuracy, credibility, and completeness are non-negotiable. The tool may be visible to the client during the session, so its presentation directly reflects on UBTI's professionalism.

## Product Purpose

SAT automates database discovery and migration readiness assessment across SQL Server and Microsoft Fabric. It replaces weeks of manual T-SQL scripting with a structured, reproducible workflow covering 25+ dimensions: schema complexity, PII indicators, dependency mapping, performance signals, governance posture, and more. The output is a professional report that decision-makers can act on. Success looks like a consultant running a full assessment of a multi-hundred-table estate in minutes, handing a client a report that would have taken a DBA six weeks to produce manually.

## Brand Personality

Intelligent, Clear, Trustworthy. The tone is expert-confident — never overexplaining, never decorating. SAT is the kind of tool that earns trust by showing its work precisely, not by looking impressive. It should feel like the sharpest instrument in the room, not the flashiest.

## Anti-references

- **Generic SaaS dashboards:** Hero-metric templates, gradient cards, big-number stats with decorative accents. SAT surfaces real findings, not vanity metrics.
- **Startup / consumer apps:** Rounded corners, soft palettes, playful copy, emoji-heavy states. Wrong register entirely.
- **Cluttered data grids:** Wall-to-wall tables with no visual hierarchy, no breathing room. Information density is a requirement; visual chaos is not.
- **Legacy Microsoft tooling (SSMS):** Dense grey forms, modal-heavy flows, no typographic hierarchy. The past this tool replaces.

## Design Principles

1. **Precision over decoration.** Every element serves the finding. If a visual element doesn't carry information, it costs attention — cut it.
2. **Data density with dignity.** High information density is required, but it must be structured. Hierarchy, whitespace rhythm, and typographic contrast make dense layouts readable rather than overwhelming.
3. **Confidence through clarity.** The UI should communicate that SAT knows what it found. Clear labeling, unambiguous status signals, and no hedging in copy.
4. **Professional enough to show a CFO.** At any moment, a consultant should be able to turn their screen toward a client executive. Nothing embarrassing, nothing that looks "beta."
5. **Speed is a feature.** The tool should feel instant. Interactions should have zero unnecessary steps, zero friction, zero loading-state theatre.

## Accessibility & Inclusion

WCAG AA minimum. Primary users are technical professionals, typically on high-resolution monitors in office or client-site environments. Reduced motion should be respected. Color is used for status signals (error, warning, success, neutral) — all states must be distinguishable without color alone (icon + label pairing required).
